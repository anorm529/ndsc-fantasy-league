# NDSC Fantasy League

Separate Next.js project workspace for the NDSC Fantasy League.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Set `DATABASE_URL` in `.env` before running Prisma migrations.
